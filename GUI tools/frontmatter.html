Frontmatter Helper

If you're uncomfortable editing the 11ty character frontmatter manually, this tool exists to help you generate a valid OC. :)

Load Exisiting Character

Main Info

All items with a * are required for a functional OC. All items with ** are required AND must be unique across all OCs. Creator name and url are optional.

Worlds & Tags

Separate by commas. Quotes around names are not necessary UNLESS you want a world or tag to display surrounded by quotes or apostrophes. In this case you will have to surround it with quotes of the opposite type OR escape them with a backslash (\) (eg. you want "World", put '"World"' or "\"World\"" as the name)

Basic Info

Basic Info Key/Value pairs. Keys cannot contain HTML, values can (in case you want to link to a species sheet or whatever).

Profile Header Options

All of these are optional. Subtitle can contain HTML.

Songs

Anything with * is required for song to show.
