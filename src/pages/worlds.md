- This page automatically generates a list of your worlds.
- You may write a description here regarding all of your worlds until you define metadata for the world.
- Create a World by adding it to a character's frontmatter. It will be treated like a tag.
- To define the metadata for the world, create a page for the world in the **worlds** folder. This will allow you to control things like title case and give the world page a custom description.
- Put the world name in the character's frontmatter to place them in the world.
