An eleventy-based, Toyhouse-inspired character directory website starter.

- Database-free, (mostly) drag-and-drop organization and character addition.
- Folders are based directly on your file structure, but the site also supports flat views of all characters!
- Uses [Eleventy](https://11ty.dev/) to generate static pages that you can host on places like Neocities, Nekoweb, Cloudflare, and GitHub Pages.
- Check out [**the repo**](https://github.com/paw/eleventy-character-directory) for full details.
